# ByByte.DIY Lessons

[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC_BY--SA_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by-sa/4.0/)

This repository contains educational lessons and learning materials for the ByByte open robotics and STEM ecosystem.

Lessons from this repository are automatically integrated into the main ByByte platform and published on the official website.

The repository includes:

* robotics lessons
* STEM materials
* project-based learning content
* examples and exercises

All lessons are designed to support accessible, open, and collaborative technical education.
