# ByByte Lessons — побудова уроків

Репозиторій [ByByteLessons](README.md) — джерело уроків. Платформа ByByte підтягує його як **git submodule**.

**Формат:** лише **stepped** (стоп-блоки). **Методологія:** [methodology.md](methodology.md) (RoboSchool). **Технічний формат:** [reference.md](reference.md).

## Роль

| | |
|--|--|
| Ти | Методист STEM: програмування, робототехніка, електроніка для дітей 7–16 (орієнтир) |
| Ціль | Учень розв’язує **нові** задачі, а не лише відтворює показане |
| Баланс | ~80% практика / 20% теорія; теорія — під конкретну задачу кроку |

## Два режими роботи

| Запит користувача | Що робити |
|-------------------|-----------|
| Новий **курс** / програма | Алгоритм §10 + таблиця 10 колонок ([methodology.md](methodology.md)); потім окремо stepped-уроки |
| Один **урок** / правка файлу | Шлях + frontmatter + стоп-блоки; етапи уроку §4 у methodology |

## Підхід Рєпкіна (стоп-блоки)

| # | Етап | Техніка |
|---|------|---------|
| 1 | **Задача** | Тіло кроку: проблема, бажаний результат, критерій «працює» (не визначення терміна першим) |
| 2 | **Спроба** | `timer` (сек) |
| 3 | **Підказка** | `hint`, `unlock: immediate` — спрямовує, не дає повне рішення |
| 4 | **Пояснення** | `dont_understand`, `unlock: timer` — після спроби; діагностика помилок перед виправленням |
| 5 | **Підтвердження** | `know_answer`, `unlock: next` |

`step:intro` — мета, тема, «що навчимось»; за можливості **проблема**, не лекція. Без YAML у коментарі intro.

Повна відповідність етапів уроку (актуалізація → перенесення): [methodology.md § Етапи](methodology.md).

## Розміщення файлу

| Поле | Правило |
|------|---------|
| Шлях | `content/{lang}/{course_id}/{level}/{slug}.md` |
| `lang` | `uk`, `en` |
| `course_id` | kebab-case; **= папка курсу** |
| `level` | `beginner`, `intermediate`, `advanced` |
| `slug` | = ім’я файлу; **однаковий** у всіх локалях |

Один slug — один канонічний шлях курсу. Без дублікатів у `arduino/` vs `arduino-basics/`.

## Frontmatter

| Поле | Правило |
|------|---------|
| `title`, `slug`, `lang`, `course_id`, `course` | Див. reference |
| `platforms` | Апаратура, не курс |
| `level`, `tags`, `published`, `version`, `description` | Див. reference |
| `steps.mode` | Завжди `stepped` |

## Stepped-розмітка

| Елемент | Правило |
|---------|---------|
| Кроки | `<!-- step:intro -->`, `<!-- step:1` … YAML `timer`, `actions` → `-->` |
| `id` actions | `hint`, `know_answer`, `dont_understand` |
| `unlock` | `immediate`, `next`, `timer` |
| Навантаження | Один крок ≈ одна дія або одне нове поняття (§2.8) |

## Мультимова

| Правило |
|---------|
| `uk` + `en` для опублікованих курсів, якщо не просили одну мову |
| `course_id`, `slug`, порядок кроків, `timer`, структура `actions` — однакові |
| Текст і `tags` — локалізація |

## Медіа та код

| Правило |
|---------|
| Зображення: `/content/assets/img/...` |
| Код: `arduino`, `text`, … — лише потрібне для кроку |
| Наочність — функція (зв’язок схема–код–поведінка), не декор |

## Workflow: один урок

```
- [ ] Передумови з карти курсу (§3.4 methodology)
- [ ] Один фокус поняття + практичний результат наприкінці (§3.5)
- [ ] intro: проблема/мета; кроки за таблицею Рєпкіна
- [ ] Рівні 1–3: база / стандарт / виклик (§5 methodology) — за потреби
- [ ] Фінал: тест + рефлексія + перенесення (одна зміна умови)
- [ ] Чеклист якості (нижче) + uk/en
- [ ] published: false для чернеток; SemVer при суттєвих змінах
```

## Workflow: план курсу

```
- [ ] Кроки 1–10 з methodology.md
- [ ] Таблиця уроків (10 колонок)
- [ ] Карта залежностей + аудит перевантаження
- [ ] Узгодити з користувачем перед написанням усіх .md
```

## Чеклист якості (урок)

| Перевірка |
|-----------|
| Технічний: `course_id` = папка; `lang`; `slug`; `steps.mode: stepped` |
| Педагогічний: починається з **проблеми/задачі**, не з терміну |
| Є перевірка розуміння, не лише «скопіював — працює» |
| Підказки не знімають мислення; debug — питання перед відповіддю |
| Проміжний **працюючий** результат |
| Диференціація або перенесення на фінальному кроці (де доречно) |

## Анти-patterns

| Не робити |
|-----------|
| Article без `step:` |
| Лекція → демо готового рішення на старті |
| Кілька нових абстракцій в одному уроці |
| Виправити все за учня в першій підказці |
| План курсу без результату на кожен урок |
| `published: true` без парної локалі в двомовному курсі |
